## Referencia de `slides.yaml`

| Campo | Valores |
| --- | --- |
| `type` | title, section, content, split, quote, code, image, video, chart |
| `animation` | fade, zoom, slide, stagger, reveal, none |
| `transition` | none, fade, slide, convex, concave, zoom |
| `theme` | light, dark |
| `background` | color, gradient, image, video, size, opacity, loop |
| `autoSlide` | milisegundos; 0 lo desactiva |
| `hidden` | true la saca del flujo normal |
| `stack` | lista de slides verticales |
