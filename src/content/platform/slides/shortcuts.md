## Atajos

| Tecla | Acción |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | Slide anterior y siguiente |
| <kbd>↑</kbd> <kbd>↓</kbd> | Moverse dentro de un stack |
| <kbd>S</kbd> | Vista de presentador con notas |
| <kbd>T</kbd> | Cambiar entre tema claro y oscuro |
| <kbd>Esc</kbd> | Vista general de todas las slides |
| <kbd>F</kbd> | Pantalla completa |
